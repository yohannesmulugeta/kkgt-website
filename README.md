# KKGT Import Export Website

Official website redesign project for **Kelbesa Kekeba General Trading (KKGT Import Export)**.

## Brand
- Primary green: `#126433`
- Primary orange: `#F06721`
- Supporting dark green: `#062A1A`

## Scope
The current website presents KKGT across four core business areas:
1. Ethiopian coffee export
2. Agricultural commodity export
3. Agrochemical import and distribution
4. General import and trading

## Deployment
This repository is configured for GitHub Pages through `.github/workflows/pages.yml`.

## Content note
Company details were consolidated from the existing KKGT website. Product technical specifications, registrations, certificates, team details and quantitative claims should be verified with KKGT before being added to production content.
